\begin{enumerate}
  \item Can the finite set $\Omega$ vary with the height bound $B$?
  \item Can the power-saving error in~\eqref{eq:counting} be made effective?
  \item Which geometric hypotheses guarantee positive local density?
\end{enumerate}
